Sobre o PlayNime
PlayNime
Versão 1.0

O PlayNime é uma plataforma criada para você organizar, descobrir e acompanhar os seus animes favoritos de forma simples e bonita.

O que oferecemos

• Lista de favoritos organizada
• Pesquisa rápida de animes
• Interface moderna e escura
• Experiência focada no usuário

Desenvolvimento

Este aplicativo foi desenvolvido com dedicação para oferecer a melhor experiência possível aos fãs de anime.

Obrigado por usar o PlayNime!
